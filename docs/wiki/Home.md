# Downloads organiser

A small Python tool that sorts the files of a folder into sub-folders by file type. It is a solution to Day 98 (Custom Automation) of the Udemy course "100 Days of Code: The Complete Python Pro Bootcamp". It is safe by design: dry run first, an undo log for every run, and no file is ever overwritten.
